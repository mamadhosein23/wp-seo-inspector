# 🔧 FixPanel — Repair Service Management Dashboard

A professional, bilingual (Persian/English) admin panel designed for 
managing home appliance repair services. Built as a role-based system 
with distinct permissions for Admins and Technicians.

## ✨ Key Features
- 🌐 Full bilingual support (Persian/English) with RTL/LTR layout switching
- 🌓 Light & Dark theme modes
- 👥 Role-based access control (Admin / Technician)
- 📋 Repair order management with status tracking
- 🛠️ Technician profiles & specialization management
- 💰 Service catalog & pricing management
- 👤 Customer database with order history
- 📊 Statistical dashboard with charts (Recharts)
- 📅 Appointment calendar/scheduling
- 🔔 Notification syste

## 🛠️ Tech Stack
- **Frontend:** React.js + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Charts:** Recharts
- **Fonts:** Vazirmatn (Persian) / Inter (English)
